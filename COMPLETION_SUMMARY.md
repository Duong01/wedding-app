## 📊 Technical Specifications

### Color System
All themes use **CSS custom properties** (CSS variables) for easy theming:
```css
.theme-wrapper {
  --primary-color: #...;
  --secondary-color: #...;
  --accent-color: #...;
  /* ... */
}
```

### Animation Framework
- **Keyframe-based animations** using CSS `@keyframes` for optimal performance
- **Staggered delays** for sequential element appearance
- **Smooth cubic-bezier timing functions** for natural motion
- **Infinite loops** for continuous decorative animations
- **Vendor-independent** (no prefixes needed for modern browsers)

### Responsive Design
All themes include media queries for:
- **Desktop:** Default styling (full-width optimization)
- **Tablet:** 768px breakpoint (adjusted padding, font sizes)
- **Mobile:** 420px breakpoint (minimal padding, single-column layouts)

### Component Architecture
**Standard Component Set (12 per theme):**
1. OpeningScreen - Invitation reveal animation
2. WeddingHero - Main hero section with date/names
3. WeddingCouple - Groom/Bride information
4. WeddingStory - Love story timeline
5. WeddingEvents - Wedding ceremony/reception details
6. WeddingCountdown - Days/Hours/Minutes/Seconds countdown
7. WeddingGallery - Photo gallery with modal
8. WeddingMap - Venue location map
9. Timeline - Event timeline/itinerary
10. WeddingGifts - Gift registry with QR codes
11. WeddingWishes - Guest book/comments section
12. WeddingFooter - Footer with monogram and copyright

### State Management
- **Computed properties** for reactive data binding
- **Conditional rendering** based on settings flags (ShowHero, ShowCouple, etc.)
- **Array safety** checks for optional data fields
- **Date formatting** using dayjs library
